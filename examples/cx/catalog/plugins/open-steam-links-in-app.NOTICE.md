# OpenSteamLinksInApp

This CX port independently implements DevilBro’s BetterDiscord plugin behavior. Desktop hands plain Steam message links to the installed Steam client. Mobile hands eligible HTTPS links to the operating system so it can open Steam if the app is installed and associated. Discord handles masked links and URLs outside the allowlist.
