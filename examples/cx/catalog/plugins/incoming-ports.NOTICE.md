# Incoming message and call ports

These GPL-3.0-or-later ports adapt behavior from existing CloudCord plugins.

- StickerBlocker by Samwich.
- SilenceUsers by DKA.
- ReplyPingControl by ant0n, MrDiamond, and Key.
- IgnoreCalls by TheArmagan and thororen.
- KeywordNotify by camila314 and x3rt.
- MessageNotifier by cassie and mochie.

The [desktop client license](../../../../desktop/client/LICENSE) contains the GPL text.
