# Outgoing message ports

These GPL-3.0-or-later examples adapt features from CloudCord and BetterDiscord plugins.

- ClearURLs by adryd and thororen.
- Ingtoninator by zyqunix and BioTomateDE.
- PolishWording by Samwich and WKoA. The available source options are apostrophes, expand, capitalize, and punctuation.
- Signature by Vee, Rini, ImBanana, and KrystalSkull.
- AutoVaporwave and ZeroWidthSanitizer by rootpoi, kraethis, and ewlle.
- NoReplyMention by DustyAngel47, rae, pylix, and outfoxxed.
- DoubleClickToReply uses a CloudCord implementation of the shortcut described by Atamol. The CX version uses an unmodified double-click on desktop and a double-tap on mobile. [Original shortcut description](https://github.com/Atamol/BetterDiscordPlugins/tree/efad6c53bfacaca5ae92d5133245e0b172351ae0/DoubleClickToReply)
- NoConfirmPin independently implements Skamt's pin and unpin shortcut as an explicit message menu action. [Original plugin](https://github.com/Skamt/BDAddons/tree/0a3e33fc679677183946ab40f3c19121b461de79/NoConfirmPin)
- SendTimestamps by Vee, GGTyler, and Grzesiek11.
- ScheduledMessages adapts the session-only mobile command by mmeta and prism.
- Translate adapts the mobile slash command by Vee, AshtonMemer and koish1.
- SilentMessageToggle by Nuckyz, CatNoir, and Z1xus. The CX version sends silently while enabled, which also covers the behavior of BetterDiscord’s AutoSilentMessage by glorytotheprc. [Pinned BetterDiscord source](https://github.com/BiscuitCleaner/BetterDiscordPlugins/blob/c011b402b927bcd9d091eda4d43bd263c5207e50/AutoSilentMessage.plugin.js)
- TextReplace by AutumnVN, TheKodeToad, Etorix, and Ape.
- EmbeddedURLs by rootpoi, kraethis, and ewlle (Endcord).
- LinkConverter by Kaan uses the upstream default destinations for Reddit, X, Instagram, TikTok, YouTube, and Bluesky. Edit the CX rules to choose different origins or destinations. [Pinned BetterDiscord source](https://github.com/zrodevkaan/BDPlugins/blob/8419ffe6f4e180fe9a755cd3bf82c5649c173b99/Plugins/LinkConverter/LinkConverter.plugin.js) · [Upstream license](https://github.com/zrodevkaan/BDPlugins/blob/8419ffe6f4e180fe9a755cd3bf82c5649c173b99/LICENSE)
- SedEnhanced by dawn, Willow, and kat. The CX correction uses literal text with the `g` and `i` flags and keeps the original message if the replacement would be empty.
- MessageBurst by port. The CX rule merges ordinary text from the same author and channel inside the configured window.
- The eight TypingQuirk ports adapt poff_null’s BetterDiscord plugins. The converter records the pinned source and Unlicense provenance for each port. [Upstream TypingQuirk sources](https://github.com/poff-null/discord-plugins/tree/80e362d9133630e051953d43d001a2fca5a49c5f)

The [desktop client license](../../../../desktop/client/LICENSE) contains the GPL text.
