# Incoming message and call ports

These GPL-3.0-or-later ports adapt behavior from existing CloudCord plugins.

- StickerBlocker by Samwich.
- SilenceUsers by DKA.
- ReplyPingControl by ant0n, MrDiamond, and Key.
- IgnoreCalls by TheArmagan and thororen.
- KeywordNotify by camila314 and x3rt.
- MessageNotifier by cassie and mochie.

The [desktop client license](../../../../desktop/client/LICENSE) contains the GPL text.

## Message filtering

NoBlockedMessages adapts the chat filtering feature by rushii, Samu, jamesbt365, Elvyra, and Etorix. The CX rule can target blocked users, ignored users, or both.

BlockKeywords by catcraft and secp192k1 matches literal words and phrases in message text and embed titles or descriptions. ClientSideBlock by Samwich and KamiRu filters chat by author ID. Both use CX source settings. Regular expressions, profile and voice filtering, and changes to content outside chat remain features of their original plugins.

## Native client effects

- SilentTyping by Vee, Rini, ImBanana, and Etorix uses a session-wide switch for outgoing typing.
- NoPendingCount by amia hides friend request counts. The original desktop plugin also has separate controls for message requests and Nitro offers.
- AlwaysAnimate by FieryFlames adapts the mobile animation hooks for avatars, banners, and server icons.
