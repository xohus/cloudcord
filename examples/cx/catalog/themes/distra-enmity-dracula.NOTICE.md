# Theme sources

The CX adaptations preserve the source palettes and include the chat wallpapers for Dreamy and Glorious Sunset. Both JPEGs were resized to a 1920-pixel longest edge and re-encoded to fit the CX image limit. Dracula is a palette port of the BetterDiscord theme.

- [Moss](https://github.com/OMetaVR/Distra/blob/a521173d4957f2b9f15194b11c649f698d8b741d/builtin-themes/distra/moss.json)
- [Lotus](https://github.com/OMetaVR/Distra/blob/a521173d4957f2b9f15194b11c649f698d8b741d/builtin-themes/enmity/lotus.json)
- [Mars](https://github.com/OMetaVR/Distra/blob/a521173d4957f2b9f15194b11c649f698d8b741d/builtin-themes/enmity/mars.json)
- [Mist](https://github.com/OMetaVR/Distra/blob/a521173d4957f2b9f15194b11c649f698d8b741d/builtin-themes/enmity/mist.json)
- [Nord for Enmity](https://github.com/OMetaVR/Distra/blob/a521173d4957f2b9f15194b11c649f698d8b741d/builtin-themes/enmity/nord.json)
- [Dreamy](https://github.com/OMetaVR/Distra/blob/a521173d4957f2b9f15194b11c649f698d8b741d/builtin-themes/vendetta/dreamy.json) ([wallpaper](https://github.com/OMetaVR/Distra/blob/a521173d4957f2b9f15194b11c649f698d8b741d/builtin-themes/backgrounds/dreamy.jpg))
- [Glorious Sunset](https://github.com/OMetaVR/Distra/blob/a521173d4957f2b9f15194b11c649f698d8b741d/builtin-themes/vendetta/glorious-sunset.json) ([wallpaper](https://github.com/OMetaVR/Distra/blob/a521173d4957f2b9f15194b11c649f698d8b741d/builtin-themes/backgrounds/glorious-sunset.jpg))
- [Dracula for BetterDiscord](https://github.com/dracula/betterdiscord/blob/77e73629086e5b77381f87b255b9f96401c61ced/base.css)
