# Catppuccin palettes for CloudCord

These CX themes adapt the four Catppuccin for Discord base palettes and all 56 flavor and accent combinations from Catppuccin for mobile Discord. They carry each preset's raw and semantic colors for its selected light or dark mode. The desktop adapter applies the portable palette and the color tokens it supports. The original Themes+ icon overlays, desktop syntax highlighting, and automatic light-mode fallback are separate features.
