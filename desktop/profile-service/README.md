# CloudCord shared profiles

CloudCord automatically publishes Fake Profile JSON while the feature is enabled. A private edit key allows later editor changes to update the same record. The service stores the public Discord user ID used for discovery and only the fields from the Fake Profile editor. It never receives Discord passwords, user tokens, BotCord tokens, email addresses, or phone numbers.

CloudCord desktop and mobile discover shared profiles directly by Discord user ID. No invisible marker is inserted into the user's About Me, and unmodified Discord clients are unaffected.
