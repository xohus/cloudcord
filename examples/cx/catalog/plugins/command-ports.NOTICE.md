# Command ports

These GPL-3.0-or-later examples adapt command behavior from the existing CloudCord plugins.

- GoogleThat by Samwich and KrystalSkull.
- ShipCalc and VibeCheck by rootpoi, kraethis, and ewlle.
- MoreCommands by Arjix, amy, Samu, zyqunix, ShadyGoat, thororen, Korbo, nyx, Samwich, Fafa, JacobTm, and voidbbg.

The [desktop client license](../../../../desktop/client/LICENSE) contains the GPL text.

## Profile menu ports

- CopyUserURLs by castdrian.
- CopyUserMention by Cortex and castdrian.
- CopyProfileColors by Crxa, Cortex, and Gir0fa.

AvatarGrabber is adapted from the Endcord plugin by rootpoi, kraethis, and ewlle.

The converter adapts the mobile command interfaces for InRole by nin0dev, ReadAllNotifications by kemo and KrystalSkull, and SpotifyShareCommands by katlyn. InRole uses a local chat reply listing loaded members. The original desktop modal, context menu and sidebar button are separate interfaces.
