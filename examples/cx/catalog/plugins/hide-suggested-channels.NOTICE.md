# HideSuggestedChannels

This GPL-3.0-or-later CX port adapts the [Endcord plugin](../../../../desktop/client/src/endcordplugins/HideSuggestedChannels/index.tsx) by rootpoi, kraethis, and ewlle. The port hides the section for the active CX session. On mobile it targets Discord’s suggested channels section in Favorites. The [desktop client license](../../../../desktop/client/LICENSE) contains the GPL text.
