# Outgoing message ports

These GPL-3.0-or-later examples adapt features from the existing CloudCord plugins.

- ClearURLs by adryd and thororen.
- Ingtoninator by zyqunix and BioTomateDE.
- PolishWording by Samwich and WKoA. The available source options are apostrophes, expand, capitalize, and punctuation.
- Signature by Vee, Rini, ImBanana, and KrystalSkull.

The [desktop client license](../../../../desktop/client/LICENSE) contains the GPL text.
