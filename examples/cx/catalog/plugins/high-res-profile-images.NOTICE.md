# High-Res Profile Images

This CX port adapts High-Res Profile Images by Z'ark Ashveil. It defaults to 256 pixels and lets the user choose a larger size in the CX source. It raises the minimum size for Discord CDN avatar URLs and leaves already larger requests alone.
