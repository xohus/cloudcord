# Catppuccin palettes for CloudCord

These CX themes adapt the base, mantle, crust, text, subtext0, and blue colors of the four Catppuccin for Discord flavors. They apply a single palette to Discord at a time. The upstream Discord theme also supplies icon recoloring, additional tokens, code highlighting, and a light-mode fallback for the dark flavors.
